# Upstream provenance

Venture Lab is derived from
[`jintukumardas/opportunity-engine`](https://github.com/jintukumardas/opportunity-engine)
at commit [`4dfb274872b5c57be0fc9a3694530506178707d0`](https://github.com/jintukumardas/opportunity-engine/commit/4dfb274872b5c57be0fc9a3694530506178707d0).

The upstream project was created by Jintu Das and distributed under the MIT
License. Its copyright notice remains unchanged in this repository's
[`LICENSE`](LICENSE), and Jintu remains credited in the package metadata.

Venture Lab adds the evidence-governed business research layer, deterministic
G0–G7 policy, immutable pilot provenance, official-source adapters, direct
OpenAI transport, expanded tests, and the `op venture` command group.

This repository begins with a clean source-history commit rather than copying the
entire upstream Git graph. That choice avoids redistributing unrelated upstream
promotional videos, voice/music assets, and bundled fonts whose third-party
terms were not independently verified for this release. The upstream repository
remains the canonical source for that history and media.
